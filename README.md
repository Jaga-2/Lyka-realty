# LYKA Realty AI

**AI-Powered Real Estate Intelligence Platform**

LYKA Realty AI is a real estate platform designed to help customers explore Dubai properties, receive personalized recommendations, compare listings, and connect with real estate consultants.

## Features

* **AI Property Consultation:** Natural-language assistance for property discovery and recommendations.
* **Multilingual Experience:** English and Tamil/Tanglish support where implemented.
* **Property Search:** Search and filter property listings from the existing inventory.
* **Property Comparison:** Compare property options to support informed decisions.
* **Voice Interaction:** Voice-based consultation where supported.
* **Customer Relationship Management:** Lead management, customer records, and agent handoff workflows.
* **Site Visit Management:** Support for property viewing requests.
* **Role-Based Access:** Separate access for customers, employees, and administrators.

## Technology Stack

* **Frontend:** React, TypeScript, Vite
* **Backend:** Python, FastAPI
* **Database:** SQLite
* **AI Integration:** OpenAI API

## Getting Started

1. Clone this repository.
2. Install the dependencies listed in the backend and frontend project files.
3. Configure your local environment using `.env.example`.
4. Add your API credentials to the local backend `.env` file.
5. Start the application using the project's documented startup script.

The application is designed to serve the frontend and backend through a single local URL.

## Configuration and Security

* Never commit `.env` files, API keys, passwords, or tokens.
* Keep customer information and production databases private.
* Use placeholder values in `.env.example`.
* Follow the project's existing authentication and authorization rules.

## Project Status

Under development. AI availability depends on valid OpenAI API configuration and access. Voice and other integrations should be tested in the running environment.
